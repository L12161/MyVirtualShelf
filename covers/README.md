# Covers

Put book covers and film posters in this folder, then point to them in `data.js`, e.g. `cover: "covers/dune.jpg"`.

- Use lowercase names with dashes, no spaces: `project-hail-mary.jpg`
- JPG, PNG or WebP all work. About 600 px wide is plenty.
- Videos don't need a cover: the YouTube thumbnail is used automatically.
